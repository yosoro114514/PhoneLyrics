# PhoneLyrics v0.1.0 — 预发布

首个准备公开的 Windows x64 AMS 便携版本。建议在 GitHub Release 中标记为 Pre-release，面向愿意反馈蓝牙连接和显示兼容性的使用者。

## 包含

- iPhone AMS 媒体通知、播放／暂停按钮及只读播放进度。
- 透明桌面歌词、暖金描边等配色、字号／单双行与鼠标穿透。
- 浮窗／任务栏切换、主副屏选择、托盘与单实例。
- 自包含单文件 EXE，内置 .NET / Windows Desktop Runtime 10.0.12；无需预装运行库。
- 原创图标、MIT 项目许可、第三方许可与 SHA-256 校验文件。

歌词取自播放器通过 AMS Title 字段传来的媒体文字。实测网易云音乐需要开启锁屏歌词；双行显示当前和上一条文字，不提前取得下一句。

## 实际验证

Windows 11 x64（10.0.26200）、iOS 26、网易云音乐：AMS 数据、已有连接的播放控制与整秒暂停位置对照；透明浮窗、125%／150% 任务栏及单实例。当前发布候选另做只读手机连接、有效位置、浮窗／任务栏切换检查；本轮未再次触发手机播放控制。

构建与 29 项协议、时间线、参数及任务栏布局检查在本机通过。程序自包含配置已检查；测试电脑原本装有 .NET，因此没有将本机启动等同于无 .NET 的干净机器实测。

## 已实现但未完整验证

上一首／下一首的手机曲目对照、Explorer 重启、显示器插拔、休眠恢复、只读目录回退、其他蓝牙适配器及长期运行。GitHub Actions 构建流程已配置，尚未运行。

## 已知限制

- 独立冷启动仍可能依赖手机链接帮助建连；已有连接不依赖读取手机链接界面。
- 断线后需手动重新连接，没有自动重连。
- 进度仅显示，不支持从电脑调整手机播放位置。
- 没有完整 LRC 同步、逐字高亮、联网歌词搜索或音频延迟校准。
- 任务栏只支持横向布局；Windows 10、ARM64 和未测 DPI 没有兼容承诺。
- EXE 尚未数字签名。

发布 ZIP 包含一个 EXE、操作说明和许可，不包含设备名称、个人设置、原始日志或真实歌曲截图。详细验证边界见源码中的 `docs/VALIDATION.md`。
