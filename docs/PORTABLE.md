# PhoneLyrics 便携版

Windows x64 的实验版本。手机播放声音，PhoneLyrics 显示手机推送的媒体文字；当前实测为 Windows 11、iOS 26、网易云音乐。

1. 将整个压缩包解压到一个可写文件夹，然后双击 `PhoneLyrics.exe`。无需管理员权限，无需预装 .NET。
2. 先在 Windows 蓝牙设置中配对 iPhone，并在手机上播放音乐。网易云音乐开启「锁屏歌词」后，才能通过媒体文字显示当前歌词。
3. 若显示未连接，使用「··· → 打开手机链接」帮助建连，等待 iPhone 连接后选择「重新连接手机」。已有连接成功后可以关闭手机链接窗口。
4. 悬停浮窗显示工具条；点击「任务栏」切换模式，任务栏悬停后的「↗」切回浮窗。
5. 从系统托盘恢复界面、解锁、重新连接或退出。进度条仅供显示，不能拖动。

连接恢复仍需手动操作，不能保证脱离手机链接独立冷启动。上一首／下一首按钮取决于播放器能力；没有完整歌词下载、LRC 或逐字高亮。

设置保存在 EXE 旁的 `overlay-settings.json`，日志在 `diagnostics/`；不可写时回退到 `%LOCALAPPDATA%\PhoneLyrics`。这两个目录／文件在运行后创建，不属于发布包。反馈问题前请移除日志中的设备名称、个人路径及媒体内容。

多个已配对 BLE 设备时，退出已有实例，再使用精确设备名称启动：

```powershell
.\PhoneLyrics.exe overlay --device-name "你的 iPhone 名称"
```

本版本未做数字签名。下载后 Windows 可能显示未知发布者；请核对来源及提供的 SHA-256，不应关闭系统防护来运行程序。运行库可能在用户临时目录建立缓存。
